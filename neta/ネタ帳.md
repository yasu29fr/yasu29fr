# ネタ帳（@yu._.fukui）

思いついたこと、あったこと、引っかかっていることを、そのまま書き足す場所です。
整える必要はありません。単語でも、言いかけでも構いません。日付も要りません。

投稿を作る担当（compose）が毎晩ここを読んで、使えそうな断片を拾います。

**置き場所を Google ドキュメントからこのファイルに移しました（2026-09-14）。**
毎朝 7:00（日本時間）に `.github/workflows/neta-collect.yml` が「書き足す場所」の下へ追記します。
予約画面の「記録」からもここに入ります。手で足すときも、下の「書き足す場所」に足してください。

## 紹介する商品

**ここではもう管理していません。** 商品リストは X のリポジトリの
`neta/商品.jsonl` 1つだけで、X と yu はどちらも同じものを読みます。
同じ日には両方のアカウントで同じ商品が出ます。

- 集める: `scripts/商品を取る.mjs`（X のリポジトリ。毎週月曜に在庫を10件まで補充）
- 成績をつける: `scripts/商品の成績.mjs`（X のリポジトリ。両アカウントの数字を突き合わせる）
- 選ぶ: `scripts/商品.py`（日付から決めるので、乱数も使用済みの記録も要らない）

`使ったことがある` を `true` にした商品だけ、「使ってみて」という書き方ができます。
既定は false で、そのあいだは「気になっています」「まだ試していません」しか書けません。
