# テロップ一括調整（Premiere Pro 拡張パネル）

タイムラインで選んだ複数のテロップ（文字ツールのグラフィック / 普通のクリップ）の
**スケール** と **位置・整列** をまとめて調整する Premiere Pro 用パネルです。

## できること

| 機能 | 内容 |
| --- | --- |
| スケール指定 | 選んだ全テロップを同じスケール(%)にする |
| スケール倍率 | 今のスケールに ×% （例: `90` → 1 割縮小。大きさの違うテロップの比率は保ったまま） |
| スケール加算 | 今のスケールに ＋/− |
| スケールを揃える | 先頭クリップ（いちばん左のクリップ）のスケールに合わせる |
| 整列（フレーム基準） | 左 / 左右中央 / 右 / 上 / 上下中央 / 下。余白(px)指定可 |
| 整列（先頭クリップ基準） | X だけ / Y だけ / 両方を先頭クリップに揃える |
| 位置 | 座標(px)を指定、または相対移動 |
| まとめてコピー | 位置・スケール・幅スケール・回転・アンカーを先頭クリップからコピー |

- **対象** で「テキストレイヤーのトランスフォーム」（プロパティパネル／エッセンシャルグラフィックスで触る値）か、
  「クリップのモーション」（エフェクトコントロールのモーション）かを選べます。自動はテキスト優先。
- キーフレームがある値は、すべてのキーに同じ操作をかけます（倍率なら動きを保ったまま縮小）。
- 縦横比の固定が OFF のクリップは、幅スケールにも同じ操作をかけます。
- 取り消しは Premiere の「取り消し(⌘Z / Ctrl+Z)」で。ただし値ごとに 1 ステップずつ戻ることがあります。

## インストール

1. このリポジトリを ZIP でダウンロードして展開（または `git clone`）
2. インストーラを実行
   - **Mac**: `tools/install-mac.command` をダブルクリック
     （「開発元を確認できない」と出たら右クリック →「開く」）
   - **Windows**: `tools/install-win.bat` をダブルクリック
3. Premiere Pro を再起動
4. メニュー **ウィンドウ > エクステンション > テロップ一括調整**

インストーラは次の 2 つをしているだけです。

- 自作（未署名）の拡張機能を読み込めるよう `PlayerDebugMode` を 1 にする
- 拡張機能フォルダにコピー
  - Mac: `~/Library/Application Support/Adobe/CEP/extensions/com.yasu29fr.telopbatch`
  - Win: `%APPDATA%\Adobe\CEP\extensions\com.yasu29fr.telopbatch`

アンインストールは上のフォルダを削除するだけです。

## 使い方

1. タイムラインでテロップを複数選択（Shift / ⌘ クリック、ドラッグ選択）
2. パネルの **選択を読み込む** を押す → 選択数と先頭クリップの値が表示されます
3. 各ボタンを押すと、選択中の全クリップに適用されます

「先頭クリップ」は **開始時間がいちばん早いクリップ** です（同時刻なら上のトラック）。

## 注意・制限

- **整列はアンカーポイントの位置で揃えます。** Premiere のプロパティパネルの整列ボタンは
  文字の外枠（バウンディングボックス）で揃えますが、スクリプトからは文字の外枠サイズが取れないため、
  完全に同じ動きにはなりません。
  → テキストのアンカーを揃えたい側に置いておく（左揃えの文字なら左端など）と、狙いどおりに揃います。
- テキストの **段落の揃え（左揃え・中央揃え）やフォント** などの文字設定は、
  Premiere のスクリプト API から安全に変更できないため対象外です。
- うまく効かないときは **調査: 先頭クリップのエフェクト構成を表示** を押すと、
  そのクリップのエフェクトとパラメータ名が出ます。その内容を共有してもらえれば対応できます。

## ファイル構成

```
CSXS/manifest.xml   拡張機能の定義（Premiere 2020 以降）
index.html          パネル画面
css/style.css       見た目
js/main.js          パネルのボタン処理（Premiere に命令を送る）
jsx/host.jsx        Premiere の中で実際に値を書き換える処理（ExtendScript）
tools/              インストーラ（Mac / Windows）
.debug              開発用: Chrome で http://localhost:8088 を開くとパネルをデバッグできる
```

## 技術メモ

- CEP（HTML パネル）+ ExtendScript で作っています。Premiere 2020〜2026 で動く方式です。
- 位置は内部的に 0〜1 の正規化座標なので、シーケンスのフレームサイズで px に換算しています。
